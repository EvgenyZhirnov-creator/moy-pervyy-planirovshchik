# Мой первый планировщик

Планировщик продаж инвестиционных продуктов: ОПИФ, ЗПИФ, ИСЖ, НСЖ и РДУ.

[Открыть планировщик в браузере](https://evgenyzhirnov-creator.github.io/moy-pervyy-planirovshchik/)

Приложение показывает недельные планы, фактические продажи, прогноз, дефицит и комиссионный доход. В нём есть календарь встреч, расписание действий, история недель, резервные копии JSON и отчёты CSV/печать. Руководитель просматривает импортированные снимки сотрудников.

## Запуск

Для работы нужны только `index.html`, `style.css` и `script.js` в одной папке. Сборка и установка зависимостей не требуются. GitHub Pages публикуется из корня ветки `main`.

Все введённые данные хранятся в localStorage конкретного браузера. Переход с локального файла на опубликованный сайт не переносит данные автоматически: выгрузите JSON в старой версии и восстановите его на сайте. Храните резервные копии.

## Документы и проверки

- `concept.md` — концепция.
- `tz.md` — техническое задание.
- `plan.md` — этапы и история разработки, результаты проверок и незавершённая приёмка на физическом телефоне.
- `checks/*.cjs` — необязательные автоматические проверки для окружения Node/Playwright/Edge; они не нужны для запуска приложения.
- `isp-planner-mobile.zip` — архив трёх файлов приложения для переноса.

`.nojekyll` отключает обработку сайта Jekyll при публикации статических файлов через GitHub Pages.
